¿Qué son los condicionales?

Los condicionales en Python permiten ejecutar diferentes bloques de código dependiendo de si una condición es verdadera (True) o falsa (False).

Ejemplo básico

El condicional más simple usa if:

x = 10
if x > 5:
    print("x es mayor que 5")

Condicional if-else

Usa if para una condición y else para manejar lo contrario:

x = 3
if x > 5:
    print("x es mayor que 5")
else:
    print("x no es mayor que 5")

Condicional if-elif-else

Para múltiples condiciones, usa elif:

x = 8
if x > 10:
    print("x es mayor que 10")
elif x > 5:
    print("x está entre 6 y 10")
else:
    print("x es 5 o menor")

Usando operadores lógicos

Combina condiciones con and, or y not:

x = 7
if x > 5 and x < 10:
    print("x está entre 6 y 9")

if x < 5 or x > 10:
    print("x no está entre 5 y 10")

if not (x == 8):
    print("x no es igual a 8")
